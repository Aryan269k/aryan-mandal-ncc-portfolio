# Aryan Mandal — NCC Portfolio Website

A responsive olive-green, black and gold NCC portfolio made with plain HTML, CSS and JavaScript. No build tools are needed.

## 1. Add your own photos
Put your images in the `assets` folder and use these exact filenames:
- `profile.jpg` — main uniform/profile photo
- `gallery-1.jpg` — parade or training
- `gallery-2.jpg` — camp
- `gallery-3.jpg` — group/activity
- `gallery-4.jpg` — certificate or award

JPG is recommended. If your file is PNG, either convert it to JPG or update the filename in `index.html`.

## 2. Personalize the content
Open `index.html` and update:
- About Me paragraph
- Your actual rank, unit, group and city
- Real medals, certificates and camps
- Optional public contact/social links

Do not publish claims about awards or ranks that are not yours. Avoid posting personal ID numbers or private documents.

## 3. Preview on your phone or computer
Open `index.html` in a browser. You can also edit the files using a code editor such as VS Code.

## 4. Publish free with GitHub Pages
1. Sign in at https://github.com/
2. Create a **new public repository** named `aryan-mandal-ncc-portfolio` (or another available name).
3. Upload `index.html`, `style.css`, `script.js`, and the whole `assets` folder.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then press **Save**.
7. Wait a minute or two. GitHub will show your live website URL on the Pages settings screen. It will usually look like `https://YOUR-USERNAME.github.io/aryan-mandal-ncc-portfolio/`.

## Files
- `index.html` — page content
- `style.css` — responsive olive/black/gold theme
- `script.js` — mobile navigation
- `assets/` — your own photos
